# 유비온 금융데이터 분석 부트캠프

금융 도메인
- 디지털 금융 환경 변화에 대응할 수 있도록 금융 이론과 업권별 구조, 자산 운용 전략, 리스크 분석 등 폭넓은 금융 도메인 지식을 학습했습니다. 디지털 전환(DX)과 AI 기술의 발전이 금융 서비스에 미치는 영향을 이해하고, BaaS, 마이데이터 등 주요 트렌드 및 국내외 디지털 뱅크 사례를 분석했습니다. 또한, 투자 수익률과 위험 관리의 기초부터 증권/기업가치 평가, 파생상품, 외환시장 이해, 자산 배분 전략까지 다양한 금융 상품과 투자 전략을 학습했으며, 퀀트 투자와 로보어드바이저, 초개인화 마케팅 및 예측 마케팅 등 최신 데이터 기반 금융 실무 전략까지 폭넓게 습득했습니다.
